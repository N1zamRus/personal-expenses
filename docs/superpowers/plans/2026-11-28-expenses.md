# Personal Expenses Implementation Plan

**Goal:** Выполнить issue № 1: ввод расходов, список и общая сумма с сохранением в браузере.

**Architecture:** Статическая страница использует стандартные HTML, CSS и JavaScript. Суммы хранятся в целых копейках; записи сохраняются в localStorage с уведомлением при ошибке записи.

**Tech Stack:** HTML, CSS, JavaScript, Node.js для тестов.

**Spec:** Критерии issue № 1 и согласованный вариант в диалоге: без сервера и зависимостей, сохранение в браузере.

## Global Constraints

- Название и категория обязательны; сумма — положительное число с не более чем двумя знаками после запятой.
- Не добавлять сервер или зависимости; не терять введённые данные молча при ошибке сохранения.

## Review Focus

- Пустые или состоящие из пробелов поля не принимаются.
- Ноль, отрицательные и некорректные суммы не принимаются.
- Дробные суммы складываются без ошибок двоичной арифметики.
- Недоступное хранилище не выдаётся за успешное сохранение.
- Текст пользователя отображается как текст, а не HTML.
