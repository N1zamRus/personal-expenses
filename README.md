# personal-expenses
Учебное приложение для учёта расходов: добавление записей, список и общая сумма.

Откройте `index.html` в браузере. Данные хранятся в этом браузере на этом устройстве; очистка данных сайта удалит записи. Суммы вводятся с не более чем двумя знаками после запятой.

Для запуска проверок установите Node.js и выполните `node test.js`.
